# TypeScript Assignment

## Overview

This repository contains my solutions to the TypeScript assignment. I have practiced different TypeScript concepts and tried to understand how they work through coding examples.

## Assignment Topics

The assignment covers the following topics:

1. Function with optional parameters.
2. Type narrowing using union types.
3. Rest parameters and readonly tuples.
4. Generic functions for concatenating arrays.
5. Interfaces and filtering objects.
6. Generics with `keyof` and indexed access types.
7. Classes, inheritance, and access modifiers.
8. Promises and asynchronous functions.
